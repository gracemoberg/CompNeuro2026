# CompNeuro2026

### Code for APPM 5370, Fall 2026

Each HW assignment has its own folder and files associated with each problem are named accordingly (i.e., files pertaining to problem 5 of HW1 will be named `prob_5_filename.ext`). If all code for one problem is contained within the file, parts of each problem are labeled in comments.

### Contents
- hw1
  -  `p4_run_pliaf.m`
  -   `p5_find_rheobase.m` (requires `hh_sim.m`)
- hw2
  -  `prob_1c.m`
  -  `prob_2c.m`
  -  `prob_4d.m`
  -  `prob_5c.m`
- hw3
  -  `prob_1c.m` simulates periodically forced LIF model, plots forced and unforced firing number, marks tongue boundaries
  -  `prob_2c.m` numerically measure PRCs for forced LIF and FHN oscillator
  -  `prob_4c.m` simulate gap-junction coupled QIF neurons with finite symmetric threshold
